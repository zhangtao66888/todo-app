# Todo App

一个基于 Vue 3 + Vite 的待办事项应用。

## 技术栈

- Vue 3
- Vite
- JavaScript

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 项目结构

```
todo-app/
├── index.html
├── package.json
├── vite.config.js
└── src/
    ├── App.vue
    ├── main.js
    └── style.css
```

## 预览

打开 http://localhost:5173 查看应用。
